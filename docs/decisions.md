## Deferred minors (final review)

- position not saved on system pauses (focus loss, noisy, notification) — up to 5 s lost if the process dies.
- Media3Backend.setSources waits only for READY/error; restoring at the very end of the last item could wait forever.
- SettingsStore.set assigns each edit's result, so two concurrent edits can apply out of order in memory.
- MainActivity captured by container.notificationPermission after destroy (held until the next activity).
- page-pack retries use exponential backoff (not a flat 30 s), timeout runs count toward the 3 attempts, and the card shows 0 / 604 during backoff.
- the pack can start at the default 1080 bucket on first launch (lastPage 1) on a non-1080 phone.
- zoom cancels an in-flight hi-res render on every pan event.
- a download killed after its last byte gets HTTP 416 on resume and is marked failed instead of done.
- SVG LRU stamps run ahead of the clock after a big pack.
- Review Focus 3 test makes the fetcher fail rather than the mask write (the write path is handled, not tested).
- initialLoad() runs on every recomposition of PageArt (only the first value is used).
